BROKER CONNECTION PATH

MT4 / MT5 integration

Nexa Bot can be connected to MetaTrader through a broker-approved Expert Advisor (EA), a secured bridge, or a supported trading API. This static website does not connect to a broker or place trades.

Recommended safe setup

  1. Choose and confirm the broker and platform (MT4 or MT5).
  2. Build and test an Expert Advisor against a demo account first.
  3. Use server-side credentials/secrets; never place broker passwords or API secrets in website JavaScript.
  4. Add explicit user consent, order-size/risk limits, stop controls, logs and a kill switch.
  5. Require a separate opt-in before enabling live execution; keep it disabled by default.
Live auto-trading requires broker-specific integration, a tested EA/bridge and secure infrastructure. No broker connection or guaranteed performance is included in this starter ZIP.
